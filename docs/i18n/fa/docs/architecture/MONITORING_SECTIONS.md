## ناوبری سطح بالا

نوار کناری داشبورد (پس از گروه B) این بخشهای سطح بالا را بهترتیب دارد:

```
خانه
ارائهدهندگان
ترکیبها
کلیدهای API
تنظیمات
تحلیلها
هزینهها          ← جدید (گروه B، طرح 16)
پایش              ← سازماندهی مجددشده (گروه B، طرح 16)
...
```

## بخش هزینهها (جدید، سطح 1)

پیشوند مسیر: `/dashboard/costs/`

| مورد              | URL                                  | توضیحات                                      |
| ----------------- | ------------------------------------ | -------------------------------------------- |
| نمای کلی          | `/dashboard/costs`                   | داشبورد تجمیعی هزینهها (منتقلشده از تحلیلها) |
| قیمتگذاری         | `/dashboard/costs/pricing`           | جدول قیمتگذاری بهازای هر مدل                 |
| بودجه             | `/dashboard/costs/budget`            | آستانههای بودجه + هشدارها                    |
| اشتراکگذاری سهمیه | `/dashboard/costs/quota-share`       | مخزنهای اشتراک سهمیه + میزان استفاده         |
| پیکربندی طرح      | `/dashboard/costs/quota-share/plans` | تنظیمات اختصاصی طرح برای هر ارائهدهنده       |

**دلیل**: قیمتگذاری، بودجه و اشتراکگذاری سهمیه پیشتر در
`پایش > پارامترهای هزینهها` قرار داشتند. انتقال آنها به یک بخش مستقل سطح بالا
باعث میشود بدون پیمایش در ابزارهای مشاهدهپذیری بهراحتی قابل دسترسی باشند.

## بخش پایش (سازماندهی مجددشده)

بخش پایش اکنون **فعالیت را در بالا** و پس از آن **3 زیرگروه** دارد:

```
پایش
├── فعالیت                 ← خوراک خط زمانی (مورد سطح بالا)
├── گروه گزارشها
│   ├── گزارشها (همه)
│   ├── گزارشهای پروکسی
│   └── گزارشهای کنسول
├── گروه ممیزی
│   ├── گزارش ممیزی
│   ├── ممیزی MCP
│   └── ممیزی A2A
└── گروه سیستم
    ├── سلامت
    └── زمان اجرا
```

### تغییرات نسبت به ساختار قدیمی

| قبل                                                                                    | بعد                                          |
| -------------------------------------------------------------------------------------- | -------------------------------------------- |
| فعالیت = زبانهای در گزارشها که گزارش ممیزی را نمایش میداد                              | فعالیت = خوراک مستقل (`/dashboard/activity`) |
| گروه پارامترهای هزینهها در پایش                                                        | به بخش هزینهها منتقل شد                      |
| فهرست تخت: گزارشها، فعالیت (گزارشها)، ممیزی، سلامت، زمان اجرا، قیمتگذاری، بودجه، سهمیه | ساختار 3گروهی + بخش مستقل هزینهها            |

## فعالیت در برابر گزارش ممیزی

این دو اکنون از یکدیگر متمایز هستند:

| بُعد                 | فعالیت (`/dashboard/activity`)                           | گزارش ممیزی (`/dashboard/audit`)          |
| -------------------- | -------------------------------------------------------- | ----------------------------------------- |
| **هدف**              | خوراک رویداد کاربرمحور («اخیراً چه اتفاقی افتاده است»)   | گزارش انطباق / امنیت                      |
| **منبع داده**        | `GET /api/compliance/audit-log?level=high`               | `GET /api/compliance/audit-log?level=all` |
| **قالب**             | خط زمانی، گروهبندیشده بر اساس روز، افعال خوانا + آیکونها | جدول متراکم صفحهبندیشده، 50 مورد/صفحه     |
| **فیلترها**          | دستهبندی نوع رویداد                                      | اقدام، شدت، عامل، بازه زمانی              |
| **خروجی گرفتن**      | در دسترس نیست                                            | خروجی JSON                                |
| **فیلتر عامل**       | کاربرد ندارد                                             | قابل فیلتر بر اساس عامل                   |
| **رویدادهای نمایشی** | فقط اقدامات سطح بالا (فهرست مجاز)                        | همه رویدادهای ممیزی                       |

### فهرست مجاز اقدامات سطح بالا

در `src/lib/audit/highLevelActions.ts` تعریف شده است. این فهرست تعیین میکند کدام
رویدادها در خوراک فعالیت نمایش داده شوند. فهرست مجاز شامل موارد زیر است:

- رویدادهای افزودن/حذف/آزمایش ارائهدهنده
- ایجاد/بهروزرسانی/حذف ترکیب
- چرخه عمر کلید API (ایجاد، لغو، چرخش)
- رسیدن به آستانه بودجه
- ورود/خروج احراز هویت
- ایجاد نشست عامل ابری
- ثبت ابزار MCP
- ایجاد/حذف وبهوک
- تغییرات مخزن/طرح سهمیه (اقدامات `quota.*`، گروه B)
- رویدادهای پلتفرم (بهروزرسانی، استقرار)
- نصب/حذف مهارت

رویدادهایی که در این فهرست نیستند، فقط در گزارش ممیزی نمایش داده میشوند.

### افزودن یک اقدام سطح بالای جدید

فایل `src/lib/audit/highLevelActions.ts` را ویرایش کرده و رشته اقدام را به
`HIGH_LEVEL_ACTIONS` اضافه کنید. این کار به PR نیاز دارد (فهرست در کد قرار دارد و
از طریق DB قابل پیکربندی نیست). آیکون متناظر را میتوان به
`src/lib/audit/activityIcons.ts` اضافه کرد.

## تغییر مسیر: `/dashboard/logs/activity`

مسیر قدیمی `/dashboard/logs/activity` بهصورت دائمی (HTTP 308) و از طریق
`permanentRedirect()` در
`src/app/(dashboard)/dashboard/logs/activity/page.tsx` به
`/dashboard/activity` هدایت میشود.

شناسه قدیمی نوار کناری، یعنی `logs-activity`، در `HIDEABLE_SIDEBAR_ITEM_IDS`
حفظ شده است (اما از `SIDEBAR_DEFINITIONS` حذف شده است) تا از خراب شدن تنظیمات
ازپیشذخیرهشده کاربران که به شناسه قدیمی ارجاع میدهند، جلوگیری شود.

## i18n

فضاهای نام افزودهشده توسط گروه B:

| کلید فضای نام           | پوشش                                                        |
| ----------------------- | ----------------------------------------------------------- |
| `sidebar.costsSection`  | برچسب بخش هزینهها                                           |
| `sidebar.activity`      | مورد فعالیت در نوار کناری                                   |
| `sidebar.logsGroup`     | برچسب زیرگروه گزارشها                                       |
| `sidebar.systemGroup`   | برچسب زیرگروه سیستم                                         |
| `sidebar.costsOverview` | مورد نمای کلی هزینهها                                       |
| `activity.*`            | همه رشتههای صفحه فعالیت (عنوان، افعال، فیلترها، وضعیت خالی) |

زبان مرجع اصلی `en` است. سه زبان دیگر (`de`، `fa`، `tr`) از طریق
سازوکار بازگشت `next-intl` (پیکربندیشده در `src/i18n/config.ts`) به زبان
انگلیسی بازمیگردند.

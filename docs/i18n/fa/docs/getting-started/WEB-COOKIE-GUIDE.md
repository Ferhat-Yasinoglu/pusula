# Web Cookie Providers (فارسی)

🌐 **Languages:** 🇺🇸 [English](../../../../getting-started/WEB-COOKIE-GUIDE.md) · 🇩🇪 [de](../../../de/docs/getting-started/WEB-COOKIE-GUIDE.md) · 🇹🇷 [tr](../../../tr/docs/getting-started/WEB-COOKIE-GUIDE.md)

---

ارائهدهندگان Web Cookie به Pusula اجازه میدهند بهجای کلید API، از طریق نشست فعلی مرورگر شما از یک سرویس هوش مصنوعی استفاده کند. این ارائهدهندگان زمانی مفید هستند که از قبل از طریق وبسایت یک سرویس به آن دسترسی دارید و میخواهید Pusula از همان نشست احراز هویتشده استفاده کند.

برخلاف ارائهدهندگان مبتنی بر کلید API، ارائهدهندگان Web Cookie با استفاده از اطلاعات احراز هویتی که مرورگر شما به وبسایت ارسال میکند، احراز هویت میشوند.

---

# پیش از شروع

> **مهم:** همیشه اطلاعات احراز هویت را از یک **درخواست زنده شبکه** کپی کنید، **نه** از محل ذخیرهسازی کوکیهای مرورگر.

بسیاری از مشکلات احراز هویت بهدلیل کپیکردن کوکیها از محل اشتباه رخ میدهند.

## از Cookie Storage کپی نکنید

بیشتر مرورگرها کوکیهای ذخیرهشده را از مسیر زیر نمایش میدهند:

```
DevTools
→ Application (یا Storage)
→ Cookies
```

اگرچه ممکن است این کوکیها صحیح به نظر برسند، احتمال دارد:

- قدیمی باشند
- ناقص باشند
- فاقد کوکیهایی باشند که فقط در درخواستهای احراز هویتشده ارسال میشوند

استفاده از این مقادیر ممکن است باعث شکست احراز هویت شود، حتی اگر معتبر به نظر برسند.

## از یک درخواست زنده کپی کنید

در عوض، از کوکیهای یک درخواست موفق استفاده کنید:

```
DevTools
→ Network
→ صفحه را تازهسازی کنید
→ یک درخواست چت یا مکالمه را باز کنید
→ Request Headers
→ Cookie
```

هدر درخواست `Cookie` شامل اطلاعات احراز هویت دقیقی است که مرورگر شما با موفقیت استفاده کرده است.

برای بیشتر ارائهدهندگان Web Cookie، این همان مقداری است که باید در Pusula جایگذاری شود.

---

# راهاندازی عمومی

فرایند راهاندازی برای بیشتر ارائهدهندگان Web Cookie یکسان است.

1. وارد وبسایت ارائهدهنده شوید.
2. Developer Tools مرورگر را باز کنید.
3. زبانه **Network** را باز کنید.
4. صفحه را تازهسازی کنید.
5. یک درخواست چت یا مکالمه احراز هویتشده را باز کنید.
6. اطلاعات احراز هویت موردنیاز را کپی کنید.
7. Pusula را باز کنید.
8. به **Providers → Add Provider** بروید.
9. ارائهدهنده Web Cookie خود را انتخاب کنید.
10. اطلاعات احراز هویت را جایگذاری کنید.
11. روی **Test Connection** کلیک کنید.
12. ارائهدهنده را ذخیره کنید.

اطلاعات احراز هویت دقیق موردنیاز به ارائهدهنده بستگی دارد.

# قالبهای اطلاعات احراز هویت ارائهدهندگان

وبسایتهای مختلف اطلاعات احراز هویت را به روشهای متفاوتی ذخیره میکنند. برخی فقط به کوکیها نیاز دارند، درحالیکه برخی دیگر ممکن است به هدرها یا توکنهای اضافی نیاز داشته باشند.

| ارائهدهنده                      | قالب اطلاعات احراز هویت       | راهنمای ارائهدهنده               |
| ------------------------------- | ----------------------------- | -------------------------------- |
| Claude Web                      | هدر کامل درخواست Cookie       | `docs/providers/CLAUDE_WEB.md`   |
| ChatGPT Web (Codex)             | هدر کامل Cookie               | `docs/providers/CHATGPT_WEB.md`  |
| Gemini Web                      | _(نیازمند بررسی)_             |                                  |
| Copilot Web                     | _(نیازمند بررسی)_             | `docs/providers/COPILOT-M365.md` |
| Microsoft 365 Copilot (BizChat) | WS access_token + chathubPath | `docs/providers/COPILOT-M365.md` |
| Grok Web                        | _(نیازمند بررسی)_             |                                  |
| ...                             | ...                           | ...                              |

> با اضافهشدن ارائهدهندگان جدید Web Cookie یا تغییر الزامات احراز هویت ارائهدهندگان فعلی، این جدول را بهروزرسانی کنید.

# قابلیتها و محدودیتهای ارائهدهندگان Web Cookie

ارائهدهندگان Web Cookie از رابط چت یک وبسایت مجدداً استفاده میکنند. آنها قابلیتهای مشابه APIهای رسمی را ارائه **نمیدهند**.

## پشتیبانیشده

- احراز هویت با استفاده از نشست فعلی مرورگر شما
- دسترسی به مدلهای موجود از طریق حساب شما
- پخش جریانی پاسخهای چت
- بدون نیاز به کلید API

## پشتیبانینشده

- فراخوانی تابع
- فراخوانی ابزار
- ویرایش خودکار فایل
- گردشکارهای عاملی IDE
- قابلیتهای مختص API

این رفتار موردانتظار است و یک باگ **نیست**.

اگر به اجرای ابزار، ویرایش خودکار فایل یا سایر گردشکارهای عاملی نیاز دارید، بهجای ارائهدهنده Web Cookie از یک **ارائهدهنده مبتنی بر کلید API** استفاده کنید.

---

# نکته مهم درباره اعتبارسنجی

موفقیت در **Test Connection** یا اعتبارسنجی کوکی فقط تأیید میکند که اطلاعات احراز هویت ارائهشده ظاهراً در قالب موردانتظار هستند.

تا زمانی که Issue #7857 برطرف نشده است، اعتبارسنجی موفق **تضمین نمیکند** که ارائهدهنده بتواند با موفقیت احراز هویت شود.

اگر احراز هویت همچنان ناموفق است، بررسی کنید که اطلاعات احراز هویت را از یک درخواست زنده شبکه کپی کرده باشید، نه از محل ذخیرهسازی کوکیهای مرورگر.

---

# عیبیابی

## احراز هویت ناموفق است

بررسی کنید که اطلاعات احراز هویت از مسیر زیر کپی شده باشند:

```
Network
→ Request Headers
→ Cookie
```

و **نه** از مسیر زیر:

```
Application
→ Cookies
```

---

## کوکی در مرورگر کار میکند، اما در Pusula کار نمیکند

برخی ارائهدهندگان کوکیهایی دارند که فقط هنگام ارسال درخواستهای احراز هویتشده فرستاده میشوند.

پس از بازکردن موفقیتآمیز یک مکالمه، اطلاعات احراز هویت را دوباره از یک درخواست جدید شبکه کپی کنید.

---

## نشست منقضی شده است

ارائهدهندگان Web Cookie از نشست فعلی مرورگر شما استفاده میکنند.

اگر نشست مرورگر شما منقضی شود یا از حساب خارج شوید، باید مجموعه جدیدی از اطلاعات احراز هویت را کپی کنید.

---

## Test Connection موفق است، اما درخواستها ناموفق هستند

تا زمانی که Issue #7857 برطرف نشده است، موفقیت در اعتبارسنجی تضمین نمیکند که درخواست احراز هویت موفق باشد.

پیش از ادامه عیبیابی، اطلاعات احراز هویت خود را دوباره از یک درخواست احراز هویتشده جدید کپی کنید.

---

# نمونه ارائهدهنده

برای مشاهده راهنمای کامل و مختص یک ارائهدهنده، به مورد زیر مراجعه کنید:

- **Claude Web** — `docs/providers/CLAUDE_WEB.md`

راهنمای Claude Web فرایند کامل راهاندازی یک ارائهدهنده Web Cookie را نشان میدهد و بهعنوان پیادهسازی مرجع عمل میکند.

# بهترین شیوهها

- اطلاعات احراز هویت را از یک درخواست احراز هویتشده جدید کپی کنید.
- از استفاده مجدد از کوکیهای قدیمی خودداری کنید.
- هنگام استفاده از ارائهدهندگان Web Cookie، نشست مرورگر خود را فعال نگه دارید.
- با کوکیهای کپیشده مانند اطلاعات احراز هویت حساس رفتار کنید.
- هنگامی که به فراخوانی تابع یا گردشکارهای عاملی نیاز دارید، از ارائهدهندگان مبتنی بر کلید API استفاده کنید.

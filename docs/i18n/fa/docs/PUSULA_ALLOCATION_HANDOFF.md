# Pusula Allocation Handoff (فارسی)

تخصیص، سهمیهٔ ارائهدهنده نیست.

مخازن سهمیه مشخص میکنند که کدام کلیدهای API میتوانند از یک مخزن ارائهدهنده استفاده کنند و سیاستهای سخت، نرم یا جهشی چگونه اعمال شوند. سهمیهٔ ارائهدهنده، ظرفیت خارجیای است که توسط یک ارائهدهنده گزارش میشود یا از یک منبع صراحتاً پیکربندیشده به دست میآید. بودجههای داخلی Ghostlight محدودیتهای حاکمیتیای هستند که مدیر سیستم تعریف میکند.

عملیات `ensurePool` ایدمپوتنت است: یک مخزن یکسان بدون تغییر باقی میماند، تخصیص تغییریافته بهروزرسانی میشود و مخزنِ موجودنبوده ایجاد میشود. این عملیات برای اتوماسیون و فراخوانندگان API با دامنهٔ محدود در نظر گرفته شده است.

نقطهٔ پایانی وضعیتِ فقطخواندنی `GET /api/pusula/status` است. فرمان راستیآزمایی `npm run pusula:verify` است؛ این فرمان هیچ درخواست زندهای به مدل ارسال نمیکند.

# Free Proxies API (فارسی)

🌐 **Languages:** 🇺🇸 [English](../../../../reference/FREE_PROXIES_API.md) · 🇩🇪 [de](../../../de/docs/reference/FREE_PROXIES_API.md) · 🇹🇷 [tr](../../../tr/docs/reference/FREE_PROXIES_API.md)

---

Pusula مجموعهای گزینششده از پروکسیهای رایگان را در جدول `free_proxies` ارائه میکند که
از ارائهدهندگان خارجی (1proxy، proxifly، iplocate، webshare) همگامسازی میشود.
داشبورد این موارد را در بخش **تنظیمات ← پروکسیهای رایگان** نمایش میدهد. این سند
فیلترکردن، مرتبسازی، شمارش و گزارش خطاهای همگامسازی در سمت سرور را
که مسیر فهرست ارائه میدهد، پوشش میدهد.

## مسیر فهرست — `GET /api/settings/free-proxies`

یک بخش فیلترشده، مرتبشده و صفحهبندیشده را بههمراه تعداد کل برمیگرداند. فیلترکردن و
شمارش در SQL انجام میشود تا رابط کاربری بتواند مجموع واقعی (برای مثال `Total: 0`) را
بدون بارگذاری تمام ردیفها در حافظه نمایش دهد.

### پارامترهای پرسوجو

| پارامتر           | نوع                                | پیشفرض    | مفهوم                                                                                                      |
| ----------------- | ---------------------------------- | --------- | ---------------------------------------------------------------------------------------------------------- |
| `search`          | رشته                               | `""`      | عملگر `LIKE` حساس به بزرگی و کوچکی حروف روی ستون میزبان (و منبع).                                          |
| `protocol`        | رشته                               | `""`      | فیلتر `type`:‏ `http` / `https` / `socks4` / `socks5`. مقدار خالی = همه.                                   |
| `country`         | رشته                               | `""`      | فیلتر `countryCode`‏ (ISO-2). مقدار خالی = همه.                                                            |
| `minQuality`      | عدد                                | `0`       | فقط ردیفهایی که `qualityScore >= minQuality` دارند. `0` = بدون حداقل.                                      |
| `disabledSources` | رشته                               | `""`      | شناسههای منبع جداشده با ویرگول که باید مستثنا شوند (برای مثال `proxifly,webshare`).                        |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = امتیاز نزولی؛ `latency` = تأخیر صعودی (مقادیر تهی در انتها)؛ `recent` = `lastValidated` نزولی. |
| `offset`          | عدد                                | `0`       | نقطه شروع صفحهبندی.                                                                                        |
| `limit`           | عدد                                | `50`      | اندازه صفحه (با سقف اعمالشده در سمت سرور).                                                                 |

### پاسخ

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` مجموع فیلترشده را **پیش از** صفحهبندی نشان میدهد تا رابط کاربری بتواند
`Total: N` و `hasMore` را مستقل از یکدیگر نمایش دهد. کلیدهای `syncErrors` شناسه منبع
هستند و فقط برای منابعی مقداردهی میشود که آخرین همگامسازی آنها ناموفق بوده است؛
بنابراین نتیجه `Total: 0` هرگز بدون توضیح نخواهد بود.

## افزودن به مخزن — `POST /api/settings/free-proxies/[id]/add-to-pool`

یک پروکسی رایگان را به مخزن مدیریتشده `proxy_registry` ارتقا میدهد. ابتدا منبع
بالادستی را اعتبارسنجی میکند؛ در صورت موفقیت، شناسه پروکسی جدید مخزن و تأخیر
اندازهگیریشده را برمیگرداند.

## همگامسازی — `POST /api/settings/free-proxies/sync`

تمام منابع فعال (یا زیرمجموعه مشخصشده در `{ "sources": [...] }`) را دوباره دریافت میکند. هر
منبع بهصورت مستقل همگامسازی میشود؛ منبع ناموفق در `syncErrors` ثبت میشود و
سایر منابع همچنان تکمیل میشوند، بنابراین همگامسازیهای جزئی هرگز دادههای معتبر قبلی را حذف نمیکنند.

## آمار — `GET /api/settings/free-proxies/stats`

مقادیر تجمیعی `total / inPool / avgQuality / bySource / lastSyncAt` را
بدون محتوای ردیفها برمیگرداند؛ این مسیر توسط ویجتهای سربرگ داشبورد استفاده میشود.

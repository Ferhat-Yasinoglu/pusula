Pusula تلهمتری سهمیه ارائهدهنده را از حسابداری Ghostlight جدا میکند.

## وضعیتهای واقعی

- `healthy` یعنی یک منبع، ظرفیت باقیمانده قابلاستفاده را گزارش کرده است.
- `approaching_limit` یعنی یک منبع، ظرفیت باقیماندهای برابر با آستانه پیکربندیشده یا کمتر از آن را گزارش کرده است.
- `exhausted` فقط زمانی منتشر میشود که یک منبع، ظرفیت صفر یا مصرف در حد نهایی را گزارش کند.
- `unavailable` یعنی یک منبع پشتیبانیشده نتوانسته است دادهای بازگرداند.
- `unknown` یعنی هیچ منبع پشتیبانیشدهای وجود ندارد یا هیچ محدودیتی برای ارائهدهنده شناختهشده نیست.

وضعیت ناشناخته بهمعنای اتمام ظرفیت نیست و ارائهدهنده را غیرفعال نمیکند.

منابع با این ترتیب ترجیح داده میشوند: API رسمی ارائهدهنده، API احراز هویتشده مصرف، سرآیندهای پاسخ که بهطور صریح نگاشت شدهاند، پیکربندی مدیر، تخمینهای محلی، ناشناخته. تخمینهای محلی هرگز بهعنوان دادههای صورتحساب ارائهدهنده نمایش داده نمیشوند.

سرآیندهای پاسخ فقط از طریق نگاشت صریح ارائهدهنده تجزیه میشوند. نامهای عمومی سرآیندها بهصورت سراسری مفروض در نظر گرفته نمیشوند.

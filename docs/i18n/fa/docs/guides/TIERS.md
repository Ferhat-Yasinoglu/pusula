# Pusula Tiers — User Guide (فارسی)

🌐 **Languages:** 🇺🇸 [English](../../../../guides/TIERS.md) · 🇩🇪 [de](../../../de/docs/guides/TIERS.md) · 🇹🇷 [tr](../../../tr/docs/guides/TIERS.md)

---

Pusula تعداد 352 ارائهدهندهٔ پشتیبانیشده را در 3 ردهٔ اقتصادی سازماندهی میکند. هر
درخواست بهترتیب از میان آنها عبور میکند تا یکی با موفقیت پاسخ دهد — به این ترتیب،
بدون نوشتن هیچگونه کد جایگزین، ارزانترین پاسخ قابلاستفاده را دریافت میکنید.

## ردهٔ 1 — اشتراکی

**ارائهدهندگانی که از قبل هزینهشان را پرداخت میکنید.** Pusula پیش از
منقضیشدن سهمیه، از تمام ظرفیت آن استفاده میکند.

| ارائهدهنده                    | دلیل قرارگیری در ردهٔ 1                         |
| ----------------------------- | ----------------------------------------------- |
| Claude Code OAuth             | Anthropic Pro/Team — نرخ ثابت، اغلب استفادهنشده |
| OpenAI Codex (اشتراک ChatGPT) | Plus/Team شامل سهمیهٔ Codex است                 |
| GitHub Copilot                | بهازای هر کاربر — سهمیه ماهانه بازنشانی میشود   |
| Cursor IDE                    | سهمیهٔ طرح Pro                                  |
| Antigravity / Devin Desktop   | سهمیههای داخلی                                  |

**راهبرد**: هر درخواستی را که با نقاط قوت مدل سازگار است، ابتدا به این رده هدایت کنید.
ردیاب سهمیه، زمان نزدیکشدن به بازنشانی را زیر نظر میگیرد و راهبرد ترکیبی
`reset-aware` نیز بر همان اساس اولویتبندی میکند. برای هدایت ابتدا به ردهٔ 1 و
مراجعه به ردههای پولی تنها پس از اتمام سهمیه، از شناسهٔ `auto/thrifty` استفاده کنید —
یا از `auto/subscription` استفاده کنید تا فقط از ظرفیت موجود در طرح بهره بگیرید و
در غیر این صورت درخواست را ناموفق اعلام کنید. به
[مسیریابی اشتراکمحور](../routing/SUBSCRIPTION_LADDER.md) مراجعه کنید.

## ردهٔ 2 — ارزان

**ارائهدهندگان پرداخت بهازای توکن با هزینهٔ کمتر از 1 دلار بهازای 1 میلیون توکن.**
برای کارهای پرتعداد یا پس از رسیدن سهمیههای ردهٔ 1 به محدودیت رزرو شدهاند.

| ارائهدهنده                  | قیمت (ورودی/خروجی)      | نقاط قوت             |
| --------------------------- | ----------------------- | -------------------- |
| DeepSeek V4 Pro             | $0.27 / $1.10 بهازای 1M | کدنویسی، استدلال     |
| GLM-4.5                     | $0.60 / $2.20 بهازای 1M | زمینهٔ طولانی        |
| MiniMax M1                  | $0.20 / $1.10 بهازای 1M | سرعت                 |
| Qwen Coder                  | $0.30 / $1.20 بهازای 1M | کدنویسی              |
| OpenRouter (بهینهسازی قیمت) | متغیر                   | بیش از 100 مدل، پویا |

**راهبرد**: ترکیب `cost-optimized` مدلی با کمترین هزینهٔ $/token را انتخاب میکند که
فیلتر قابلیتهای وظیفه (بینایی، حالت JSON، ابزارها، حداکثر زمینه) را برآورده کند.

## ردهٔ 3 — رایگان

**ارائهدهندگان بدون هزینه** — طرحهای رایگان، برنامههای اعتباری و سهمیههای روزانهٔ OAuth.

| ارائهدهنده       | سهمیهٔ رایگان / اعتبارها                           |
| ---------------- | -------------------------------------------------- |
| Kiro AI          | ردهٔ رایگان Claude (استفادهٔ منصفانهٔ سخاوتمندانه) |
| OpenCode Free    | بدون احراز هویت، محدودیت نرخ سخاوتمندانه           |
| Qoder            | OAuth رایگان                                       |
| Google Vertex AI | 300 دلار اعتبار برای حساب جدید                     |
| Amazon Q         | ردهٔ رایگان برای کاربران AWS                       |
| Pollinations     | API عمومی و باز                                    |
| Cloudflare AI    | ردهٔ رایگان Workers AI                             |

**راهبرد**: ترکیب `auto` با سقف بودجه، هنگامی که ردههای 1 و 2 ناموفق باشند
یا زمانی که `useFreeOnly=true` تنظیم شده باشد، درخواست را به این رده هدایت میکند.
ارائهدهندگان رایگان اغلب محدودیت نرخ سختگیرانهتری دارند — مدارشکن پس از
دورهٔ انتظار، آنها را بازیابی میکند.

## پیکربندی ردهها

داشبورد ← **ردهها** ← ارائهدهندگان خود را تخصیص دهید. مقادیر پیشفرض (از `tierDefaults.json`)
معقول هستند؛ اگر اشتراکهای خاصی برای اولویتبندی یا ارائهدهندگانی برای حذف دارید، آنها را ویرایش کنید.

امتیازدهی 16 عاملی Auto-Combo رده را نیز در نظر میگیرد. به
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md) مراجعه کنید.

## تلهمتری

داشبورد ← **مصرف** تعداد توکنهای مصرفشده در هر رده را بهصورت روزانه نمایش میدهد. از آن برای موارد زیر استفاده کنید:

- تأیید اینکه ردهٔ 1 بهطور کامل استفاده میشود (در غیر این صورت، ارزش اشتراک خود را هدر میدهید)
- شناسایی مدلهای ردهٔ 2 که بیشتر انتخاب میشوند (آنها را به 1 یا 2 مدل محدود کنید)
- اطمینان از اینکه ردهٔ 3 در بارهای کاری آزمایشی/اکتشافی باعث صرفهجویی میشود

## الگوهای رایج

### بار کاری کاملاً رایگان

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

مسیریابی را بهشدت بهسمت ردهٔ 3 سوق میدهد؛ تنها در صورت در دسترس نبودن ردهٔ 3، از ردهٔ 2 استفاده میکند.

### اشتراکمحور با جایگزین ارزان

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

فهرستی صریح و مرتب که با ردهٔ 1 ← ردهٔ 2 ← ردهٔ 3 مطابقت دارد.
